## 🏯 &nbsp; Arc Log — Projects

### 🏛️ Scheme Finder
> *"Every scheme. Every citizen. One search."*

**Stack:** `React` · `Vite` · `Tailwind CSS` · `Node.js` · `Express.js` · `SQLite (FTS5)` · `Google Gemini API`

- Built a full-stack platform to discover and check eligibility for **4,764 Indian Central and State government schemes**
- Implemented full-text search, personalized recommendations, and rule-based eligibility matching
- Integrated the Google Gemini API for AI-powered scheme explanations and natural-language queries

---

### 🕳️ Pothole Detection System
> *"Spot the cracks in the road before they break the ride."*

**Stack:** `Python` · `YOLOv8` · `OpenCV` · `Deep Learning`

- Developed a YOLOv8-based object detection system for automated pothole detection in road images
- Trained and compared two models:

| Model | Precision | Recall | mAP@50 | mAP@50-95 |
|:-----:|:---------:|:------:|:------:|:---------:|
| **YOLOv8s** | 87% | 74.1% | 83.6% | 49% |
| YOLOv8n | 69.3% | 55.9% | 57% | 27.2% |

- YOLOv8s clearly outperformed YOLOv8n across all metrics

---

### 🎙️ Voice-to-Text Translation System
> *"Speak in your language. Be understood in any."*

**Stack:** `JavaScript` · `HTML` · `CSS` · `Web Speech API`

- Developed a multilingual voice-to-text translation system supporting regional languages of India
- Implemented real-time speech recognition and converted speech into grammatically correct translated text
- Enabled voice-based interaction through multilingual text processing
